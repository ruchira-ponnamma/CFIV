FILE FINGERPRINTS

SHA-256 and SHA3-256

CFIV calculates both digests from the file bytes. Verification recalculates them and compares each result with its registered value.

DIGITAL SIGNATURES

RSA 2048-bit with RSA-PSS

Newly generated RSA keys are 2048-bit. Signatures use RSA-PSS with MGF1-SHA256. The current combined scheme signs a digest derived from both file hashes; legacy SHA-256 signatures remain supported.

PRIVATE KEY PROTECTION

Encrypted PEM storage

CFIV serializes the private key in PKCS#8 PEM using cryptography’s BestAvailableEncryption with the supplied password. The private key is kept at the configured filesystem path and is not stored in the database. CFIV does not display the key or password here.

STORAGE ACCESS

Authenticated Cloudinary resources

For Cloudinary-backed records, original files and signature artifacts are stored as authenticated raw resources. CFIV retrieves them server-side for verification; this page does not expose resource identifiers or delivery URLs.

INTEGRITY CHECK

How verification detects changes

During verification, CFIV reads the registered file, recalculates SHA-256 and SHA3-256, and compares both against the stored record. It then verifies the RSA-PSS signature using the registered public key and the record’s signature scheme. A changed file affects its hash comparison and signature check; Cloudinary signature artifacts are also checked against the signature bytes stored in the database.
